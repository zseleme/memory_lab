# Leg 01 — Dashboard Shell

## Responsibility

Assemble the React Vite web application shell featuring the dark luxury visual theme, editorial typography, full-screen Amber Cascades math-water canvas, and SVG LiquidGlass refraction components.

## Proves

- Given a browser loading the Memory Lab web dashboard
- When the application mounts
- Then typography renders cleanly and the Amber Cascades canvas runs fluidly at 60fps with zero layout shift

## Independence

Operates as a self-contained frontend client bundle that can be previewed independently with mock data.

## Yields at Pass 5B

- Initialize Vite React project structure with Tailwind CSS configuration
- Port Amber Cascades canvas animation with math rainfall and liquid wave ripple physics
- Implement LiquidGlass optical refraction button using SVG displacement map filter
